# NFC PRANK 🟣

**iOS-приложение для джейлбрейка, собранное Theos. Автор: `thxrealx7`.**

## Возможности

- Считать NDEF-текст/ссылки и UID (для MIFARE) с поддерживаемых NFC-меток.
- Записать произвольный текст или HTTP(S)-ссылку; начальный текст `created by thxrealx7`.
- Очистить **всю пользовательскую область** NTAG213/215/216: страницы 4–39 / 4–129 / 4–225 соответственно, после чего поставить пустой NDEF TLV `03 00 FE 00` на страницу 4.
- Включить парольную защиту чтения **и** записи на NTAG213/215/216 (PWD/AUTH0/PROT), затем снять её с тем же паролем.
- Генерация случайного 4-байтового (8-значного HEX) пароля и копирование его в буфер обмена.
- Постоянная блокировка lock bits и CFGLCK **не применяется**.

**Работа с чужими метками без согласия владельца не предполагается.** Не используйте с пропусками, картами оплаты, транспортными картами и критичными идентификаторами.

## Как собрать deb в GitHub

1. Создай пустой репозиторий GitHub с веткой `main` (без шаблонных файлов или с обычным README).
2. Распакуй архив и добавь **все файлы**, включая скрытую папку `.github/workflows` и папку `NFCPrank`.
3. Сделай **Commit changes**. Сборка запустится автоматически на macOS runner. Можно вручную: **Actions → Build NFC PRANK deb → Run workflow**.
4. После успешного выполнения открой **Actions → последний запуск → Artifacts → NFC-PRANK-rootless-deb**.
5. Скачай ZIP-артефакт Actions, извлеки из него `.deb` и установи с помощью Sileo/Zebra (на устройстве с rootless jailbreak).

Репозиторий собирает бинарный `.deb` без публикации секретов и без сторонних библиотек в приложении. Theos скачивается GitHub Actions во время сборки.

## Требования и ограничения

- **iPhone с NFC**, **iOS 15+**, джейлбрейк **rootless** (например, окружение `/var/jb`).
- Подпись Theos/ldid с `com.apple.developer.nfc.readersession.formats = [NDEF,TAG]`. На некоторых версиях iOS джейлбрейк-адхок подпись может не получить доступ к Core NFC. Доступ требует **проверки на реальном iPhone**.
- NDEF чтение/запись ограничено совместимостью метки и Core NFC; низкоуровневые защита и глубокая очистка ограничены **оригинальными NTAG213/215/216 с проверенным GET_VERSION**.
- Парольное ограничение не является криптографической защитой высокого уровня. Не записывайте секретные данные, полагаясь только на этот пароль.
- **Если пароль потерян, защита может стать неснимаемой.** Храни пароль в безопасном месте до проверки разблокировки. Не используйте эту функцию, если метку нельзя восстановить/заменить.
- «Полная очистка» означает только перезапись пользовательских страниц. Не очищает UID, служебные/производственные/блокировочные биты. При снятии телефона до конца страницы могут быть очищены лишь частично.
- На NTAG216 глубокая очистка длинная; сеанс Core NFC может истечь до завершения. Для крупных меток повторите очистку, если она оборвалась.
- Поле PIN можно оставить пустым для обычных незапароленных NDEF-меток. Для чтения, записи или очистки запароленной метки введите её PIN до сканирования.
- Приложение **не записывает URL на любую NFC-метку подряд**: неподдерживаемые и read-only метки не изменяются.

## Структура

- `NFCViewController.m` — интерфейс, Core NFC, чтение/запись/очистка/защита.
- `NFCPrank/Info.plist` — настройки приложения, текст запроса NFC.
- `entitlements.plist` — разрешения Core NFC, нужные при подписи.
- `Makefile`, `control` — сборка Theos / deb rootless.
- `.github/workflows/build.yml` — автоматическая сборка deb.

## Безопасный первый тест

1. Возьми **новую пустую NTAG213** без важных данных.
2. Проверь чтение, запись `created by thxrealx7` и повторное чтение.
3. Сделай очистку, снова проверь чтение.
4. Создай пароль, скопируй и **сохрани его вне приложения**.
5. Протестируй блокировку, затем разблокировку и обычную запись.

⚠️ Этот архив содержит **исходники, не предварительно собранный/протестированный `.deb`**. Здесь нет iOS SDK и Theos, поэтому двоичный пакет создаст GitHub Actions. Нужна проверка компиляции и физических NFC-операций на устройстве.
